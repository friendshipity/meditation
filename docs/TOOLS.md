# Tools Spec

## 可用工具

### `web_search`

用途：获取必要的外部信息，补足模型当前上下文盲区。

### 强约束

- **频率限制：每小时最多 5 次。**
- 在模型工具说明中必须明确写出该限制。
- 仅在“有必要”时调用，不可把搜索当默认步骤。

### 何时应调用

- 需要最新事实、实时数据或外部证据。
- 记忆中不存在相关信息。
- 用户明确要求检索或给出处。

### 何时不应调用

- 可由现有上下文或记忆完成回答。
- 只是为了“看起来更认真”而搜索。
- 本轮目标更偏联想/反思而非事实校验。

## 建议策略

1. 先检索记忆，再决定搜索。
2. 一次搜索后尽量最大化提炼，不连续无效重搜。
3. 当搜索配额接近上限时，优先保留给高价值问题。
