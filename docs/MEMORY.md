# Memory Design (Nanobot-style)

> 本项目记忆机制要求“完全参考 nanobot 记忆机制”，并引入 token 压缩能力。

## 1. 目标

- 在长对话中保留关键轨迹。
- 控制上下文 token 成本。
- 让模型在多轮反思中持续受益于历史经验。

## 2. 分层记忆

1. **短期记忆（Working Memory）**
   - 最近若干轮的原始关键信息。
   - 用于当前轮精细推理。

2. **中期摘要记忆（Episodic Summary）**
   - 将若干轮压缩成阶段摘要。
   - 保留因果链、观点变化、未决问题。

3. **长期语义记忆（Semantic Memory）**
   - 抽象后的稳定事实、偏好与策略。
   - 支持跨会话复用。

## 3. Token 压缩机制

- 定期把短期记忆归档为高密度摘要。
- 压缩时保留：
  - 关键结论；
  - 核心分歧；
  - 高价值反问；
  - 失败路径（避免重复犯错）。
- 丢弃低信息密度重复内容。

## 4. 检索与回注入

- 每轮先做记忆检索，再决定是否搜索外部。
- 注入上下文时遵循“最小充分”原则，避免把全部历史塞入提示词。

## 5. 写入策略

可采用打分写入：
- 重要性（importance）
- 新颖性（novelty）
- 可复用性（reusability）
- 与当前主题相关性（relevance）

仅高分项进入长期层。

## 6. 对外输出约束

- 最终输出必须体现 memory history 综合，而非仅当前轮结论。
- 输出中应显式包含：历史强化点、历史修正点、未解决问题。
